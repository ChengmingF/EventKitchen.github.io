Action Recognition

EventKitchen provides in total 10,762 actions segments with 268 action classes over all recording sequences. Three human annotators are assigned to annotate the synchronized RGB video. Then, the annotations are aligned to the synchronized stereo event data streams. Please refer to the paper for the annotation pipeline and statistics.

The action annotations are saved in actions/cooking_activity_action.csv under the recording session tree as described in the Download. We provide the details of the action annotations and an example script to load the action annotations in the EventKitchen toolkit.
